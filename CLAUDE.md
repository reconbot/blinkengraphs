# blinkengraphs spec

Vocabulary `CONTEXT.md`, rules `rules/`, conformance data `vectors/`, design tokens `tokens/`, decisions `docs/`. No app code lives here.

`vectors/` and `fixtures/` are generated by `cargo run -p vectors -- <this repo>` in blinkengraphs-win. Change a rule there and in `rules/` together, then regenerate.

Use the `domain-modeling` skill when a term changes and `writing-for-agents` for any doc edit. Prose earns each sentence.

Commits follow Conventional Commits. Commits, PRs and comments stay free of session links and personal or employer details; the repo is public.
